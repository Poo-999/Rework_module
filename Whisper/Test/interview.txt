สวัสดีครับ ผมชื่อจักริน กวีพันธ์ ครับ ปัจจุบันผมเป็นนักพัฒนาซอฟต์แวร์ที่โฟกัสทั้งการสร้างระบบ Full-stack และงาน Data Machine Learning ครับ จุดแข็งหลักของผมคือการเชื่อมโยงระบบฝั่ง Frontend, Backend และ Database เข้าด้วยกัน โดยมีประสบการณ์ทำงานกับ Flutter สำหรับโมบายล์แอป, Python สำหรับงาน Data Science และการสร้างโมเดล Machine Learning รวมถึงภาษาฝั่ง Backend อย่าง C# และการจัดการฐานข้อมูลอย่าง SQL Oracle ครับ สิ่งที่ทำให้ผมสนุกกับการทำงานคือการได้หยิบโจทย์จริงมาเปลี่ยนเป็นโซลูชันที่จับต้องได้ ตั้งแต่การวิเคราะห์ข้อมูล การเทรนโมเดล ไปจนถึงการขึ้นเป็นแอปพลิเคชันให้ผู้ใช้งานเข้าถึงได้ง่ายครับ 
มีโปรเจกต์หนึ่งที่ผมทำโมเดลพยากรณ์ข้อมูลสภาพแวดล้อม Time-series Forecasting เพื่อนำไปแสดงผลบน Web Application ครับ
ความท้าทายสำคัญคือ ข้อมูลตั้งต้นมีความผันผวนสูงและMissing values ค่อนข้างเยอะ ทำให้ช่วงแรกโมเดลเกิด Error สูงมาก ผมแก้ปัญหาโดยการทำ Data Preprocessing ใหม่อย่างเป็นระบบ ทั้งการคลีนข้อมูล การทำ Feature Engineering เพื่อดึงตัวแปรที่สัมพันธ์กับเวลา และทดลองเปรียบเทียบอัลกอริทึมหลายตัวเพื่อหาโมเดลที่แม่นยำและไม่ Overfit จากนั้นจึงนำโมเดลไป Deploy ผ่าน Web UI ให้ผู้ใช้งานสามารถกรอกพารามิเตอร์แล้วเห็นผลการพยากรณ์ได้ทันที โปรเจกต์นี้ทำให้ผมเข้าใจทั้งกระบวนการเตรียม Data การปรับแต่งโมเดล และการคำนึงถึง User Experience ในการแสดงผลข้อมูลครับ
ผมมองว่าในสายงานเทคโนโลยี การเปลี่ยนแปลงเครื่องมือเป็นเรื่องปกติครับ วิธีการของผมคือเน้นทำความเข้าใจ Fundamentals ก่อนเครื่องมือ เช่น ถ้าต้องใช้เฟรมเวิร์กใหม่ ผมจะดู Architecture และ Data flow ของมันเป็นอันดับแรก จากนั้นลองสร้างโจทย์เล็ก ๆ เพื่อทำ Prototype ทดสอบทันที
ส่วนการทำงานร่วมกับทีม ผมให้ความสำคัญกับการสื่อสารที่ตรงประเด็น Clear & Concise ไม่ลังเลที่จะถามเมื่อติดปัญหาเชิงโครงสร้าง และคอยอัปเดตความคืบหน้ารวมถึงจุดที่ติดขัดให้ทุกคนเห็นภาพตรงกันเสมอ เพื่อให้งานเดินหน้าต่อได้โดยไม่เสีย ขอบคุณมากครับสำหรับโอกาสในวันนี้ครับ
